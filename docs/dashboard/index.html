PHATPSY 2.0 — Projected Hamiltonian Approach to Polyatomic Systems

A Localized Valence-Bond (LVB) quantum chemistry package for polyatomic molecules, active-site embedding, and spin-catalysis / chemisorption complexes (such as NO/Ni(100)). Alternating-spin electron pairs (α ↑ / β ↓) are localized across bipartite atomic graphs and embedded within non-bonded model-potential and Phillips–Kleinman (PK) environments.

Architectural Direction: Following the Nov 13 pivot to a Localized VB-first architecture—and formalized by the Nov 22 Spin-Catalysis Flagship Acceptance Spec (PR #11, 2770953) and docs/agent-rules reframing (0ea116f)—PHATPSY 2.0 treats localized alternating-spin bonding and active-site embedding as its primary physics, scoping model-potential / PK projectors specifically to non-bonded environmental interactions.

Localized VB Engine & Python Orchestration (phatpsy/)

The phatpsy package drives Localized Valence-Bond (LVB) electronic structure and active-site embedding workflows in memory, pairing bipartite alternating-spin assignment with Clementi–Roetti and Thakkar Slater-Type Orbital (STO) basis libraries.

  • ▪
    Bipartite LVB Solver (spin.py) Assigns alternating α (↑) and β (↓) spin vectors across localized bond pairs and active-site centers.
  • ▪
    Stepwise VB Assembler (builder.py) Synthesizes molecular and chemisorption decks fragment-by-fragment with explicit spin and embedding specifications.
  • ▪
    Dataclass Deck Models (schema.py) Typed Python dataclasses (CalculationDeck, AtomConfig, SymmetrySpec) representing geometries, basis sets, and spin states.
  • ▪
    Driver, Basis & I/O (driver.py, basis.py, io.py, cli.py) In-memory execution via PhatpsyDriver, STO database lookup, YAML / legacy .stdin / JSON I/O, and CLI commands.

Fortran 2018 Compute Core (src/)

Migrates legacy FORTRAN 66 global COMMON blocks and fixed arena limits into modular ISO Fortran 2018 modules that evaluate STO integrals, subspace SCF updates, and non-bonded model-potential / PK projections.

  • ▪
    Modular State & Control phatpsy_state_mod.f90, phatpsy_contrl_mod.f90, and standalone executable phatpsy_cli.f90.
  • ▪
    Dynamic Array Allocation Replaces rigid compile-time dimension caps (MXNATM, MXNORB, MXMSTO) with runtime allocation sized to the deck.
  • ▪
    BLAS & LAPACK Backends Links against OpenBLAS or Apple Accelerate via CMake for symmetric eigensolves and linear algebra routines.
  • ▪
    Typed f2py Bindings Signature file src/_phatpsy_core.pyf and stub _phatpsy_core.pyi expose Fortran state arrays and computation stages to Python.

Quick Start & Verified API / CLI Usage

Matched directly to README.md, phatpsy/schema.py, and phatpsy/cli.py

# Prerequisites: gfortran (GCC 10+), cmake (3.18+), BLAS/LAPACK, Python 3.10+
git clone https://github.com/JackS9/phatpsy2.git
cd phatpsy2

python3 -m venv .venv
source .venv/bin/activate
pip install numpy scipy matplotlib pyyaml ipykernel pytest

# Build Fortran 2018 core, CLI executable, and _phatpsy_core f2py extension
mkdir build && cd build
cmake ..
cmake --build .
cd ..
# Build multi-stage container image from the repository root
docker build -t phatpsy:2.0 .

# Print CLI help or inspect available Clementi-Roetti / Thakkar STO basis sets
docker run --rm phatpsy:2.0
docker run --rm phatpsy:2.0 elements C

# Run an example calculation deck and export structured JSON output
mkdir -p out
docker run --rm -v "$PWD/out:/work" phatpsy:2.0 examples/CO.yaml -o /work/CO.json
from phatpsy import PhatpsyDriver, CalculationDeck

# Load the zero-net-spin CO dative-pi baseline deck
# (C: alpha up/up, O: beta down/down -> net spin = 0)
deck = CalculationDeck.from_yaml("examples/CO.yaml")

# Render interactive Three.js 3D WebGL viewer inside Jupyter Notebook
deck.show()

# Execute in-memory Localized VB / Projected Hamiltonian calculation
driver = PhatpsyDriver()
results = driver.run_deck(deck)
# Print PHATPSY CLI help
phatpsy

# Inspect available Clementi-Roetti & Thakkar STO basis sets for Carbon
phatpsy elements C

# Run calculation deck and export structured JSON output
phatpsy examples/CO.yaml -o CO.json

# Launch standalone browser Three.js 3D viewer
phatpsy view examples/n2.yaml

# Build & serve MkDocs Material user manual locally
pip install -r docs/requirements.txt
mkdocs serve
